# 客服答问卡包 · support-answer-kit

20 张真实客服场景脱敏提炼的「买家问题 → 可直接复制的回复模板」卡片，按场景分组：试用转化 / 价格异议 / 信任建立 / 交付与售后 / 流失挽回。

**给谁用**：卖数字产品 / SaaS 的独立开发者和小团队——买家问题高度重复，每次从零手写回复既慢又难保证转化话术质量。

**来源与脱敏**：全部卡片来自 OPC 两年真实客服交互，经脱敏处理（无姓名、邮箱、公司名、联系方式、内部编号、内部数字）。

**许可与口径**：开源内测免费（MIT）；托管版筹备中（不承诺永久免费，不提供报价）。

## 使用方式

1. 打开 [cards/qa-cards.md](cards/qa-cards.md)
2. 按买家问题类型找到对应卡片
3. 复制回复模板，把 `[占位符]` 替换为你的产品名/链接即可发送
